# OTT PROJECT 디자인 기준 v0.1

작성: 2026-11-08. Figma 화면 제작용 기준이며 실제 서비스 구현 명세가 아니다.

## 방향과 출처

Disney+ 모티브의 상단 탐색·대형 배너·가로 콘텐츠 목록을 유지한다. Spotify 분석 문서의 콘텐츠 중심 다크 표면·카드·검색·재생 조작 규칙을 기본으로 삼고, 홈 배너와 작품 상세에 Runway 분석 문서의 큰 이미지·어두운 오버레이를 적용한다. 관리자는 밝은 화면을 유지하면서 Linear 분석 문서의 경계선·입력창·상태 배지 표현을 프로젝트에 맞게 변형한다.

- https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/spotify/DESIGN.md
- https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/runwayml/DESIGN.md
- https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/linear.app/DESIGN.md

위 자료는 제3자가 작성한 디자인 분석이며 브랜드의 공식 디자인 시스템이 아니다. 아래 수치는 OTT PROJECT 적용을 위한 설계값이다.

## 시청자 화면

- 1440px 데스크톱 프레임. 상단 공통 탐색과 좌우 약 40px 여백을 사용한다.
- 작품 이미지가 주된 색상 요소가 되도록 배경·컨트롤은 절제한다.
- 홈 배너와 상세 배경 위에는 어두운 오버레이를 두어 제목·소개·버튼의 가독성을 확보한다.
- 목록 카드는 일관된 비율과 크기로 배치한다. 비대칭 홍보용 그리드는 쓰지 않는다.
- 재생·가입 등 주요 버튼은 흰색 바탕과 짙은 글자로 표시한다. 청록색은 선택 상태·진행 위치·포커스에 제한적으로 사용한다.
- Spotify의 녹색, 음악용 하단 고정 플레이어, 고정 사이드바는 가져오지 않는다.
- 서비스명은 OTT PROJECT. 소셜 제공자는 미정이며 버튼은 ‘소셜로 시작하기’로 표시한다.
- 처음 인증한 사용자는 닉네임 설정 후 가입 완료·홈으로 이동하고 기존 회원은 바로 홈으로 이동한다.
- 신규 회원·추천 장애는 전체 사용자 시청 기반 인기 콘텐츠 또는 최신작을 보여준다. 시청 이력이 없는 회원의 개인 목록은 빈 상태로 표시한다.

## 관리자 화면

- 밝은 바탕, 왼쪽 운영 메뉴, 표·입력 폼·상태 배지 중심으로 구성한다.
- 콘텐츠, 영상 처리, 인기 콘텐츠, 라이브 운영, 추천·학습, 감사 기록을 구분한다.
- 선택·포커스는 공통 포인트 색 계열을 사용하되 밝은 바탕에서 구분되도록 대비를 확인한다.
- 처리 상태는 색상만으로 구분하지 않고 대기·진행·완료·실패 문구를 함께 제공한다.
- 감사 조회 UI는 제안이며 FR-30의 필수 범위는 저장이다.

## Figma 구성 원칙

- Foundations: 색상·글자·간격·모서리 기준.
- Components: 탐색, 버튼, 입력창, 필터, 작품 카드, 목록 행, 상태 배지, 오류 안내, 관리자 표.
- Viewer: U-01~08 및 U-03-B.
- Admin: A-01~07 및 A-02-B/C.
- States & Flows: S-01~06과 주요 이동 흐름.
- 화면은 편집 가능한 프레임·텍스트·도형으로 구성하고 가능하면 공통 컴포넌트를 재사용한다. 단일 이미지 삽입은 완성된 Figma 편집 결과로 처리하지 않는다.
- 사용자 추가 결정(2026-11-08)에 따라 브라우저 클릭형 목업으로 확장했다. 입력·화면 이동·찜·검색·시청 위치와 운영 상태를 연결한다. 실제 OAuth·서버 세션·영상/DRM/ABR·파일 변환·AI 학습은 모의 처리하며 기능 구현 완료로 간주하지 않는다. Figma 파일은 보존하고 브라우저 수정이 자동 동기화된다고 전제하지 않는다.
- 기존 FR-01~32와 화면 ID를 유지하고 각 화면의 설명은 제품 프레임 밖에 둔다.

## 인기 콘텐츠 자동 추천 변경 (2026-11-08)

A-04 홈 편성의 콘텐츠 선택·순서·저장 기능을 제거하고 읽기 전용 인기 순위 화면으로 변경한다. U-03의 운영자 추천은 전체 사용자 시청 기반 인기 목록으로 대체한다. FR-32의 개인화 추천은 유지한다. 목업은 최근 7일, 작품당 30초 이상 시청한 고유 사용자 수 내림차순·동률 시 누적 시청 시간 순을 사용한다. 실제 집계 기준·주기는 미확정이며 시연값을 구현 확정으로 간주하지 않는다. 데이터가 없으면 최신 공개작으로 대체하고 비공개·삭제 작품은 제외한다. 기존 Figma/PDF는 이전 수동 추천 설계가 남은 참고본이다.
